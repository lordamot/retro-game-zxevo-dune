# port.txt - words the port adds for screens of its own.  These are not
# the cartridge's: the Mega Drive has no start-up screen, and no "loading"
# or "wait" anywhere in its text (orig/sega/res/text, ui.txt).  The same
# form as ui.txt; tools/dune_data.py makes each txt_port_<id> in
# text.inc.  @id "text" is one string.  Escapes: \n \" \\ \xNN {cN}.
# The characters are ASCII (charset.txt says which the fonts have) and, for
# the start-up screens' font only (FA_FONT_INTRO), Cyrillic: its letters and
# their codes are src/res/art/ui/font_cyr.txt's.

.join space

# The start-up log (front_boot_say, font FA_FONT_INTRO): a line for each
# check and each thing that goes to the sound card, "ok" or "error" after
# it, at most 38 characters.  Latin letters draw as capitals, as in every
# font here.
@boot_evo               "ZX Evo BaseConf detect"    ; the machine (evo_check)
@boot_gs                "GS detect"                 ; the sound card
@boot_mem               "GS memory"                 ; its memory test, then its size
@boot_mb                "Mb"                        ; the size in whole megabytes: "2Mb"
@boot_kb                "Kb"                        ; ... else in kilobytes: "512Kb"
@boot_init              "GS init done, loading"
@boot_fx                "Sound effects"
@boot_music             "Music:"                    ; then the tune's name
@boot_ok                "ok"
@boot_error             "error"                     ; and the start-up stops - or, for the card:
@boot_nosound           "no sound: press a key to play without"
@mus_title              "title"                     ; the tunes the music test has no name for
@mus_intro              "intro"
@mus_other              "song 18"
