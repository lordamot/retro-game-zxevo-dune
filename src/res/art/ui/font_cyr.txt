# font_cyr.txt - Cyrillic for the port's own intro screen.
#
# The one picture in src/res/ not taken out of the cartridge: the Mega
# Drive has no Cyrillic, and the intro screen's words (port.txt, the
# intro_* strings) are Russian.  The letters are drawn in the manner of the
# cartridge's font8 (src/res/art/ui/font8.png): strokes two pixels wide,
# capitals only (the cartridge draws lower case as capitals too), in a
# 7 x 7 box, and the font's black shadow one pixel right and down is added
# by the build, not drawn here.
#
# tools/dune_data.py encodes a Cyrillic letter, capital or small, by this
# file: an alias is the Latin capital of the same shape, and a drawn letter
# is $80 + its place below (0 the first).  tools/dune_front.py builds the
# font FA_FONT_INTRO from font8 with the drawn letters at glyphs 0.. (the
# text routine masks a code with $7F, so $80 + n draws glyph n; font8's
# glyphs 0-31 are frame pieces no string uses).  A drawn ASCII character
# replaces font8's own in this font only: '@', which font8 draws as a (c).
#
# alias LETTER=LATIN ...
# LETTER, then 7 rows of 7: '#' ink, '.' nothing

alias А=A В=B Е=E Ё=E К=K М=M Н=H О=O Р=P С=C Т=T Х=X
