# ui.txt - the Mega Drive Dune II's screens, as the port rebuilds them.
#
# Written by tools/sega/port_ui.py (its docstring says how each capture is reached).
# Pictures are src/res/art/ui/*.png: RGBA in the Mega Drive's own colours (v*255//7),
# alpha 0 where the VDP draws nothing.  Positions are screen pixels on the Mega Drive's
# 320x224; 'least' names the 24 lines the port's 320x200 can best do without.
# Palette lines are the 4 x 16 colours in CRAM at the capture, as RRGGBB; pen 0 is
# transparent (the backdrop).  Text is printed with a font (== fonts at the end):
# 'x y line "text"' - the palette line is the line the glyphs are drawn in.

== fonts - The fonts
   capture -   size -
   pictures (file, x, y, w x h, layer, note)
     font8.png                             -    -  128 x 64  ROM $0506C2 font title/mentat: 128 glyphs, in the mentat's line 2
     font_menu.png                         -    -  128 x 64  ROM $04F6C0 font menu: 128 glyphs, in the build panel's line 1
     font_score.png                        -    -  128 x 64  VRAM $A000 font score: 128 glyphs, as the score page has them, in its line 2
   notes
     every sheet is 16 x 8 glyphs of 8x8: glyph n is at x = n % 16 * 8, y = n // 16 * 8, and glyph n prints character n (ASCII); lower case draws the same small capitals as upper case; pen 0 is transparent, and the glyphs carry their own shadow pens, so a line is recoloured by pen, not by one colour
     font8.png (font 'title'/'mentat'): Format80 at $0506C2, 128 tiles.  The title menu and PRESENT (tile $480 + c, line 3), the mentat's text box (tile $460 + c, line 2), the end credits (tile $480 + c, lines 2 and 3).  Glyphs $00-$1F are the text box's frame and bar pieces
     font_menu.png (font 'menu'): raw at $04F6C0 (the screen table's font block $04F6BE: a length word, $1000, then the tiles), VRAM $8000 = tile $400 + c.  The build and Starport info box (line 1), the options' values and the password (drawn into sprite tiles).  $00-$1F are placeholders the panels overwrite
     font_score.png (font 'score'): tile $500 + c on the score page: the score, time, rank and figures (line 2), the bars (glyphs $18 on, lines 0 and 1)
     battle_credits_digits.png: the credits counter's own 0-9 ($050ACC is the blank, then 0-9, raw)
